블랙잭 (BOJ 2798)

문제
N장의 카드 중에서 3장을 골라, 카드의 합이 M을 넘지 않으면서 M에 최대한 가깝게 만드는 문제이다.

풀이

이 문제는 특별한 자료구조 없이 완전 탐색(Brute Force) 으로 해결할 수 있다.

카드가 최대 100장이므로, 3장을 고르는 모든 경우를 확인해도 충분히 시간 내에 해결 가능하다.

- 카드 3장을 고르는 모든 조합을 확인한다.
- 각 조합의 합을 구한다.
- 합이 M 이하일 때만 비교한다.
- 그 중 가장 큰 값을 저장한다.

해결 방법

3중 반복문을 사용해서 i, j, k를 서로 다른 인덱스로 설정하여 3장을 선택한다.

for (let i = 0; i < N - 2; i++) {
  for (let j = i + 1; j < N - 1; j++) {
    for (let k = j + 1; k < N; k++) {
      let sum = cards[i] + cards[j] + cards[k];
    }
  }
}
