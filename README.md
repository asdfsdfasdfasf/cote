블랙잭 (2798)

문제
N장의 카드 중에서 3장을 골라, 카드의 합이 M을 넘지 않으면서 M에 최대한 가깝게 만드는 문제이다.

풀이

이 문제는 특별한 자료구조 없이 완전 탐색(Brute Force) 으로 해결할 수 있다.

카드가 최대 100장이므로, 3장을 고르는 모든 경우를 확인해도 충분히 시간 내에 해결 가능하다.

- 카드 3장을 고르는 모든 조합을 확인한다.
- 각 조합의 합을 구한다.
- 합이 M 이하일 때만 비교한다.
- 그 중 가장 큰 값을 저장한다.

해결 방법

3중 반복문을 사용해서 i, j, k를 서로 다른 인덱스로 설정하여 3장을 선택한다.

<javascript>
for (let i = 0; i < N - 2; i++) {
  for (let j = i + 1; j < N - 1; j++) {
    for (let k = j + 1; k < N; k++) {
      let sum = cards[i] + cards[j] + cards[k];
    }
  }
}
                    
두 개 뽑아서 더하기
정수 배열 numbers가 주어질 때, 서로 다른 인덱스에 있는 두 수를 선택해서 더할 수 있는 모든 경우의 수를 구하고,
중복을 제거한 뒤 오름차순으로 정렬하여 반환하는 문제이다.

처음에는 단순히 두 수를 더해서 배열에 넣으면 된다고 생각했다.
그래서 모든 경우를 확인하기 위해 이중 반복문(for문)을 사용했다.
1. 첫 번째 반복문은 기준이 되는 숫자
2. 두 번째 반복문은 그 뒤에 있는 숫자들을 선택

이렇게 하면 같은 인덱스를 두 번 사용하는 경우를 자연스럽게 피할 수 있다.

for (var i = 0; i < numbers.length; i++) {
    for (var j = i + 1; j < numbers.length; j++) {
        // 두 수 더하기
    }
}
중복 제거 과정
문제를 풀면서 가장 먼저 막혔던 부분이 중복 제거였다.
처음에는 모든 값을 그냥 배열에 넣었는데,
예를 들어 [2,1,3,4,1] 같은 경우 3, 5 같은 값이 여러 번 나왔다.
그래서 중복을 제거하기 위해
includes() 함수를 사용해서 이미 있는 값인지 확인한 후 넣도록 했다.

if (!answer.includes(sum)) {
    answer.push(sum);
}
정렬
문제에서 오름차순 정렬을 요구하기 때문에 마지막에 sort()를 사용했다.
자바스크립트의 기본 sort()는 문자열 기준 정렬이기 때문에,
숫자 정렬을 위해 아래와 같이 작성했다.

answer.sort(function(a, b) {
    return a - b;
});

처음에는 중복을 고려하지 않고 모든 값을 넣어서 결과가 틀렸다.
sort()를 그냥 사용했더니 숫자가 아니라 문자열 기준으로 정렬되는 문제도 있었다.
Set을 사용할까 고민했지만, 교수님이 보기 쉽게 하기 위해 includes() 방식으로 구현했다.
이 문제는 어렵지는 않았지만, 중복 제거와 정렬 방식을 제대로 이해하고 있는지가 중요한 문제라고 느꼈다.
특히 자바스크립트에서 sort()가 기본적으로 문자열 기준이라는 점을 다시 한번 확인할 수 있었다.
